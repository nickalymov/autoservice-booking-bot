## Этап 6. Эксплуатационные замечания перед масштабированием

1. **Персистентность FSM:** Для сохранения промежуточных черновиков при
   перезапуске контейнера (`docker compose restart bot`) рекомендуется
   подключить Redis-хранилище `RedisStorage` для Aiogram.
2. **Блокировки базы данных:** Локальный `asyncio.Lock` в `BookingService`
   полностью предотвращает гонки в рамках одного контейнера бота. При
   горизонтальном масштабировании на несколько экземпляров рекомендуется
   добавить `SELECT ... FOR UPDATE` в PostgreSQL.
3. **Мониторинг квот Google API:** При интенсивных запросах отслеживать
   лимиты Google Calendar API (квоты по умолчанию: 500 запросов на 100 с).
